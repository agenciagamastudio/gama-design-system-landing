## 🎬 Roteiro de Entrevista (50-60 min)

### **FASE 1: ABERTURA (5 min)**

**Objetivo:** Build rapport + contexto

```
Boas-vindas:
"Oi [nome], obrigado por dedicar 50 minutos. Estou pesquisando
como pessoas estão usando Clone IA para melhorar a plataforma.
Sua opinião é valiosa. Ok?"

Contexto:
"Antes de começar: como você conheceu Clone IA?
E quanto tempo você está na comunidade Alan?"

Permissão:
"Posso tomar notas? (Sem gravar, só resumo)"
```

---

### **FASE 2: DESCOBERTA DO PROBLEMA (25-30 min)**

**Objetivo:** Entender JOB (funcional + emocional + social)

#### Bloco 2.1: O Trabalho Primário (Funcional)

```
Q1: "Qual é o trabalho principal que você tenta fazer?"
    Exemplos:
    - "Gerar leads qualificados"
    - "Vender mais cursos"
    - "Automatizar customer support"
    - "Monetizar meu conhecimento"

    (Deixe silêncios, oiça muito)

Q2: "Como você tenta fazer isso HOJE?
     Qual é seu processo atual?"
    (Procure: WordPress, emails, ads, atendimento manual, etc)

Q3: "Quando começou a usar Clone IA, qual era sua expectativa?
     O que você esperava que acontecesse?"
```

**ESCUTA ATIVA:**
- Não interrompa
- Procure verbatims (quotes reais)
- Tome nota de emoção (frustração, esperança, etc)

---

#### Bloco 2.2: Dor/Frustração (Emocional)

```
Q4: "O que não funciona bem no seu processo atual?"
    (Procure: time pequeno, custo alto, falta expertise, complexidade)

Q5: "Como isso afeta você emocionalmente?
     Que sentimento você tem quando isso acontece?"
    (Exemplos: frustrado, sobrecarregado, inseguro, infeliz)

Q6: "Se pudesse mudar UMA coisa no seu negócio hoje,
     qual seria?"
    (Procure: não é sempre o clone — pode ser outra coisa)
```

**DICA:** Perguntas emocionais revelam a dor REAL (não só funcional)

---

#### Bloco 2.3: Contexto Social

```
Q7: "Como seus colegas/clientes veem sua situação?
     O que eles falam?"
    (Procure: pressão de pares, comparação, reputação)

Q8: "Sua equipe (se tem) sabe que você quer usar Clone IA?
     Como eles reagem?"
    (Procure: buy-in, resistência, apoio)

Q9: "Você já viu alguém conseguir sucesso com Clone IA?
     Se sim, qual foi o resultado?"
    (Procure: case estudos reais, prova viva)
```

---

### **FASE 3: SOLUÇÃO ATUAL vs. ALTERNATIVAS (15 min)**

**Objetivo:** Entender diferenciador + competição

#### Bloco 3.1: Como Resolve HOJE

```
Q10: "Como você resolve essa dor atualmente?
      Qual ferramenta ou método você usa?"
     (Procure: manual, outras plataformas, free tools)

Q11: "Por que escolheu Clone IA em vez de [alternativa]?
      - MyPersonas
      - GPTs customizados (ChatGPT)
      - Zapier/Make
      - Contratar person
      - Outra coisa?"
     (Procure: diferenciador REAL, não marketing)

Q12: "Se Clone IA não existisse, o que você faria?"
     (Procure: alternative = seu real competitor)
```

**CRÍTICO:** Resposta a Q11-Q12 = diferenciador real vs. percebido

---

#### Bloco 3.2: Resultado Real (Behavior Validation)

```
Q13: "Você realmente criou e está usando um clone?
      (Se SIM → continue)
      (Se NÃO → ir para Q18)"

      Quando criou? [data]
      Está ativo hoje? [sim/não]

Q14: "Que resultado você teve com o clone?
      Quero ouvir dados reais:
      - Quantos leads gerou?
      - Quanto faturou?
      - Tempo economizado?"

     (Procure: números concretos, não estimativas)

Q15: "Esse resultado atendeu sua expectativa?
      Por quê?"

     (Procure: gap expectativa vs. realidade)

Q16: "Se você tivesse que avaliar em % de sucesso,
      qual seria? (0-100%)"

     (Procure: satisfação real, honestidade)

Q17: "Você recomendaria Clone IA para um amigo?
      Por quê?"

     (Procure: NPS implícito)
```

**SEÇÃO SE NÃO CRIOU:**

```
Q18: "Por que não criou ainda?"
     - Medo de errar?
     - Não sabe como?
     - Não vê valor?
     - Está esperando?
     - Outra coisa?

Q19: "O que te faria começar?"
     (Procure: barrier principal, solução necessária)

Q20: "Se tivesse que pagar R$ 1.000 para criar,
      valeria a pena?"
     (Procure: price sensitivity vs. value perception)
```

---

### **FASE 4: RETENÇÃO & USO CONTÍNUO (10 min)**

**Objetivo:** Entender churn + engagement

```
Q21: "Você ainda usa o clone que criou?
      (Se SIM)
      └─ Com que frequência?
         - Diário?
         - Semanal?
         - Mensal?
         - Ocasional?

      (Se NÃO)
      └─ Quando parou?
      └─ Por quê?"

Q22: "O que faria você CONTINUAR usando?
      Qual seria o gatilho para usar mais?"
     (Procure: feature, suporte, comunidade, etc)

Q23: "Se Clone IA cobrasse R$ 100/mês para usar,
      você pagaria?"
     (Procure: willingness to pay)

Q24: "Qual é sua maior frustração com Clone IA
      ou com a plataforma de Alan?"
     (Procure: pain point não mencionado)
```

---

### **FASE 5: FECHAMENTO (5 min)**

```
Q25: "Tem algo que eu não perguntei mas você acha
      importante compartilhar?"

Q26: "Posso voltar se tiver mais dúvidas?"

Q27: "Quer saber os resultados da pesquisa quando
      for publicada?"
     (Procure: engagement contínuo)

Agradecer:
"Muito obrigado. Suas insights vão ajudar a melhorar Clone IA.
Estou enviando um documento com resultados da pesquisa em [data]."
```

## 📊 Análise Pós-Entrevista

**Após todas as 17 entrevistas:**

1. **Síntese de Padrões** (5-7 padrões principais)
   - Qual é a dor mais mencionada?
   - Qual é o diferenciador mais citado?
   - Qual é a taxa média de sucesso?

2. **Opportunity Algorithm (Ulwick)**
   ```
   Para cada padrão:
   Oportunidade = Importância (1-10) × (Importância - Satisfação)

   Exemplo:
   - "Gerar leads": Imp=9, Sat=4 → Score: 9×(9-4) = 45
   ```

3. **Behavior Metrics**
   - % que continua usando
   - % que viu resultado
   - % que recomendaria
   - Average price sensitivity

4. **Gaps vs. Secondary Research**
   - O que dados primários confirmam?
   - O que contradiz?
   - Qual insight novo?

## 🚨 Erros Comuns a EVITAR

❌ **Não faça:**
- Leading questions ("Clone IA é bom, né?")
- Perguntas very technical (usuário não é dev)
- Múltiplas perguntas de uma vez
- Interrupções (deixe falar)
- Pitch/venda (é pesquisa, não sales)

✅ **Faça:**
- Open-ended questions
- Silêncios longos (deixe pensar)
- Perguntas simples, claras
- Oiça 80%, fale 20%
- Tome verbatim quotes
